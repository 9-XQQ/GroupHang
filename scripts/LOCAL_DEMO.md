# 一键本机演示

从项目根目录，在已有route_plan环境执行：

```powershell
python scripts/run_demo.py
```

这是独立的演示进程。需要安装项目依赖、PostgreSQL可连接，数据库账号拥有CREATE SCHEMA权限；可用TEST_DATABASE_URL指向专用测试库。没有安装依赖、迁移现有数据库或修改.env的隐式步骤。

启动后终端给出演示指南URL、本次credentials.json路径及stop路径。打开URL，先读指南，再点击“打开应用并登录”。账号demo_1为发起人，demo_2为同行；密码随机生成，仅存于本次私有运行目录，两个账号共用该演示密码。用本机编辑器打开credentials.json查看，不要提交或在录屏中展示。演示使用真实密码校验和会话流程，没有绕过登录接口。

## 隔离和标识

- 固定使用127.0.0.2的随机空闲端口，日常开发服务仍在127.0.0.1:8000；两者Cookie隔离。同时开多个演示进程会共用127.0.0.2的Cookie域，建议一次运行一个。
- 每次创建agent_demo_加32位随机十六进制schema；所有业务依赖、WebSocket、就绪检查和清理事务均使用该schema，不读取原账号和行程。
- 启动入口在子进程中关闭地图、模型及短信凭据，禁止httpx异步外部发送，不编辑.env。POI搜索来自已知合成夹具，未知搜索返回空；模型走原有规则降级，道路走真实估算逻辑，均不冒充外部服务成功。
- 应用底部始终显示“合成演示 / 模型规则降级 / 路线估算”，响应头X-Demo-Fixture为synthetic-isolated。演示横条由该进程生成，没有修改原前端文件或日常开发界面。
- 地图JS未启用，不能展示真实地图底图或导航；地点名、坐标、路线及偏好均为合成数据。夹具邻近地点只用于演示证据链，不能作为现实推荐依据。

演示指南`/demo`及`/demo/info`仅含合成环境说明、行程ID与邀请码，没有密码、token、数据库连接串或schema。其它业务接口仍要求正常认证和权限。

## 8分钟演示脚本

| 时间 | 操作 | 说明的工程能力 |
|---|---|---|
| 0～1分钟 | 打开指南，用demo_1登录，展示4个行程及5个收藏A～E对应地点 | 本机隔离、真实认证、个人收藏与共享行程边界 |
| 1～2分钟 | 演示1，多人吃饭，城市上海市，按现有时间推荐 | 多起点赴约耗时、确定性工具、预览不写入 |
| 2～3分钟 | 演示2，品牌分店，填写寿司郎 | 公平耗时与偏好理由；缺少可靠清净程度数据时说明未知 |
| 3～4分钟 | 演示3，附近半日游，锚点“演示公园入口”，返回中心 | 时间预算、收藏/候选选择、估算与返程约束 |
| 4～5分钟 | 演示3，在助手输入“生成当前路线”，查看草案再确认执行；最终确认接受估算 | action协议、人工确认、版本校验、事务提交 |
| 5～6分钟 | Network复制执行响应trace_id，打开本人追踪接口 | 决策/模型/地图/估算/事务阶段；可通过相同proposal_id重复请求验证回执重放 |
| 6～7分钟 | 演示4，先生成超时路线，再把两处停留由90改为15分钟后重算并比较 | 时间冲突、输入变更和两版方案比较 |
| 7～8分钟 | 展示评测命令和保存基线，解释真实模型超时记录 | 可复现评测、故障分类、能力边界与后续改进 |

5个收藏为演示湖畔公园、演示美术馆、演示咖啡店、寿司郎演示商场店、寿司郎演示公园店，带周末/雨天/聚餐/散步标签。demo_1私人备注对demo_2不可见；两人均已加入4个行程，不必临时补账号或位置。日期固定为2026-11-08 13:00～18:00（北京时间），冲突行程为13:00～14:00，需改日期时自行保存并重算。

所有演示道路都为估算，最终确认前必须明确接受。HTTP自检验证了拒绝未接受估算的确认、执行回执重放及同行不能读取本人trace；不把HTTP验证称为浏览器点击验收。

## 停止、重置和期限

终端Ctrl+C，或从另一终端创建本次目录内的stop文件。正常停止/TTL到期会关闭服务器、删除本次确切随机schema、删除credentials.json，将state.json标记为cleaned。默认1小时，可用`--ttl 7200`延长至最多2小时。

重置：先正常停止，再重新运行启动命令。新进程使用新随机schema和密码，数据恢复固定初始状态；不会重置日常开发数据。默认每次生成新目录，显式`--run-dir`必须是尚不存在的目录，拒绝覆盖旧运行或跟随该目录的符号链接。

强制结束进程、停电或数据库中断可能阻止清理；cleanup_failed/starting/ready状态都不能当作已清理。检查该运行state.json中确切schema后由可信本机管理员处理，不能按前缀批量删除schema。状态文件不含密码，普通退出后可保留作为本机记录。

## 真实进程自检

```powershell
$env:AGENT_DB_TESTS='1'
python -m unittest tests.test_local_demo -v
```

测试启动真实子进程，通过HTTP验证登录、三场景预览、草案/执行/重放/trace、估算确认、私密收藏、冲突修正和方案比较，最后验证schema确实不存在且凭据文件删除；另验证TTL清理及下一次启动恢复相同数据。没有调用真实地图或模型，也不创建真实用户数据。

原31条动作及12组24轮任务评测入口仍在evals文档。此演示进程只服务本机，不能作为部署入口；日常开发继续使用uvicorn app.main:app。
