# 三场景任务级评测

这是一套与原31条助手动作样例分开的补充挑战集：12组任务，每组2轮，三场景各4组。数据全部合成，冻结文件为[discovery_tasks.json](discovery_tasks.json)。在首次完整评分前冻结输入与期望；首次12/12组、24/24轮通过，没有据此修改产品代码或放宽期望。初始化曾因合成收藏缺少必填place_key失败，补齐评测夹具后才取得首次完整评分。

设计时参考了现有接口和能力，因此不能称为第三方盲测或统计独立保留集；公开并运行后应作为补充回归集。它不测真实模型对话质量、地图准确率或用户满意度。

## 运行

```powershell
$env:AGENT_DB_TESTS='1'
python scripts/evaluate_discovery.py --output-dir docs_private/discovery_evals/latest
```

需要本机PostgreSQL账号具备CREATE SCHEMA权限；可设置TEST_DATABASE_URL使用专门测试库。不设置AGENT_DB_TESTS=1会拒绝运行，不会悄悄跳过并报告成功。

运行器创建随机discovery_eval_加32位十六进制schema，建表并写入合成用户、成员、行程及收藏；退出时只删除本次创建的schema。不读取已有用户、行程、会话或凭据，不修改应用迁移版本。使用现有chat → run_discovery → discover入口、真实SQL收藏筛选、真实路线估算降级；替换外部模型、POI和道路适配器，并禁止httpx网络发送。模型和地图实际调用均为0。

每轮保留上轮结构化请求条件，应用当轮修改，再调用入口；成员补全会实际更新隔离数据库。此处的“多轮”是界面连续操作，不是自然语言指代解析、长期记忆或自主Agent循环。

## 任务与断言

| 场景 | 任务 |
|---|---|
| 多人餐饮 | 出发点缺失后补全、公平赴约耗时、收藏标签切换、时段收紧 |
| 品牌分店 | 品牌/城市缺失后补全、偏好启停、在线搜索不可用后恢复 |
| 附近半日游 | 日期时间补全、同名锚点消歧、时间预算修改、路线失败估算及返程 |

根据任务检查追问、候选数量、明确的排序期望、品牌过滤、标签结果、偏好说明、在线不可用声明、估算标记、返回路段和结束时间。空候选不能通过要求有推荐的排序/品牌/估算检查。每轮另查预览标记、私人备注不泄露、候选数量上限，以及实际数据库中没有目的地、正式计划或草案写入，行程版本未被推荐操作改变。

报告包括每轮布尔检查、组/轮通过数、场景分项、异常数、工具夹具调用次数、p50/p95和数据集/源码SHA256，不保存请求、响应原文、坐标或私人备注。任一轮失败整组失败，任一组失败命令退出1；输入或环境错误退出2。故意错误的期望也由专项回归验证确实被判失败。

最新公开合成基线见[JSON](baselines/discovery_frozen_v1/report.json)和[Markdown](baselines/discovery_frozen_v1/report.md)。工具夹具和本机数据库延迟不是线上模型或地图延迟；模型未真实调用，无法评价token、价格或模型版本优劣。推荐入口75秒整体超时与计算期间输入版本变化另有专项测试，分别检查504与409；夹具中的路线不可用是适配器返回None，之后执行真实估算代码。

CI已加入该任务门禁与Job Summary，实际云端结果需以workflow运行记录为准。后续优先补独立人工编写的盲测任务、自然语言多轮修正，以及外部服务恢复后的少量真实对照；保持已公开回归集与新盲测集分开。
